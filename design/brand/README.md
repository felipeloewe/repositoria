# Repositoria — kit de marca

Fuente operativa del aplicativo. Los SVG/PNG en `public/assets/brand/` se usan en runtime (favicon, shell, login). Esta carpeta `design/brand/` es el paquete de diseño para reutilizar fuera del UI (brochure, app stores, etc.).

## Estructura

| Carpeta | Uso |
|---------|-----|
| `web/` | Icono web / favicon (SVG + PNG + ICO + apple-touch) |
| `app/` | Icono de aplicación (SVG + PNG 256) |
| `comercial/` | Logo horizontal (claro/oscuro), marca sola y brochure PDF |

## Colores oficiales

- Navy `#1B2A6B`
- Blue `#1F529E`
- Steel `#268CB8`
- Teal `#2EC4C6`
